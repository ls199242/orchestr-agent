              OrchestrAgent 核心 API 接口速查字典
            

            
Java 核心引擎 (8080) 与 Python Mock 控制中心 (8000) 提供的所有标准接口端点与参数速查

          

        


        

          

            

              
                

                  请求方式
                  接口路径 (Endpoint)
                  服务归属
                  功能职责说明
                  典型入参 / 返回
                

              
              
                

                  POST
                  /api/agent/chat
                  Java :8080
                  SSE 实时流式会话交互
                  JSON: {strategyCode, message, sessionId, userId}
                

                

                  POST
                  /api/agent/invoke
                  Java :8080
                  异步启动多智能体策略编排工作流
                  返回 {flowId, state: "RUNNING"}
                

                

                  GET
                  /api/agent/flow/{flowId}
                  Java :8080
                  根据 flowId 查询流程执行状态、上下文与各节点输出
                  返回 {flowId, state, steps, result}
                

                

                  GET
                  /api/agent/flow/{flowId}/logs
                  Java :8080
                  检索指定 flowId 的全量执行日志行列表
                  返回 List<String> 日志行
                

                

                  POST
                  /api/agent/stop/{flowId}
                  Java :8080
                  主动中断/取消正在运行的工作流实例
                  置终态为 STOPPED，返回 Boolean
                

                

                  GET
                  /api/agent/config/overview
                  Java :8080
                  获取 7 大仓储健康状态、条目数与刷新时间
                  返回 7 仓储的健康指标数组
                

                

                  GET
                  /api/agent/config/all
                  Java :8080
                  获取 Java 内存中 7 大仓储的全量快照结构
                  返回完整 JSON 实体对象
                

                

                  POST
                  /api/agent/config/reload
                  Java :8080
                  通知 Java 核心引擎立即触发全量配置热重载
                  可选参数 repoName，返回重载结果
                

                

                  GET
                  /api/agent/logs/stream
                  Java :8080
                  SSE 实时流式日志文件监听推送
                  参数 ?tail=100&filter=xxx
                

                

                  GET
                  /admin/configs
                  Python :8000
                  拉取 Python Mock 控制台持久化的全部配置数据
                  strategies, agents, tools, models, dict
                

                

                  POST
                  /admin/configs
                  Python :8000
                  保存/更新单项配置数据并持久化到 JSON 文件
                  {category, item}
                

                

                  GET
                  /admin/mocks
                  Python :8000
                  获取所有自定义动态 Mock 规则列表
                  规则数组，包含 matchParams 与 responseData
                

                

                  POST
                  /mock/tools/{toolCode}
                  Python :8000
                  业务工具仿真 Mock 端点 (天气、画像、周边服务等)
                  根据入参动态匹配命中规则并返回 Mock 响应
                

                

                  POST
                  /mock/llm/v1/chat/completions
                  Python :8000
                  OpenAI 兼容协议的大模型仿真 Mock 端点
                  返回标准 choices / delta / message 结构
